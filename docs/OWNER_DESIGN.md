# 90+1 OWNER DESIGN BRIEF

**Genre:** Football career-mode life sim  
**Primary inspiration:** Jumpers for Goalposts 1–6  
**Presentation:** 2D/2.5D nostalgic  
**Fantasy:** One footballer's career — not managing a club

## Core Week Loop

Training → Life choice → Training → Event → Match → Consequence → Money/Fame → Next week

**Training is the default expectation.**

## Weekly Calendar Structure

- **Monday–Thursday:** Training (default expectation)
- **Friday:** Light training / recovery
- **Saturday:** Match day
- **Sunday:** Rest / social / family time

Events can override the schedule (e.g., family birthday Thursday → Attend vs Stay at training with trade-offs).

## Event Override System

Rare interruptions that break the training routine:
- Family wedding
- Girlfriend birthday
- Agent meeting
- Sponsor opportunity
- Charity event
- Media day
- Transfer meeting
- Teammate party
- Physio appointment
- TV appearance
- Awards ceremony

**Player chooses — signature system.**

## Skills System

Position-weighted skills:
- Volley
- Snapshot
- Penalty
- Passing
- Heading
- Turn & Shoot
- Free Kick
- Crossing
- Dribbling
- Tackling
- Interception
- Positioning
- Strength
- Pace
- Stamina

## Match System

**Commentary stream** with **CHANCE FOR YOU** moments:
1. Commentary progresses
2. Chance moment appears
3. Minigame launches (position → timing → click → outcome)
4. Return to commentary simulation

**Minigame types:**
- Shooting
- Set pieces
- Passing
- Defensive actions
- GK variants (if playing keeper)

## Training System

**Interactive minigames** → XP / skill / manager approval / fatigue

- Mastery widens timing window
- Specialization focuses development
- Skipping repeatedly = manager distrust + fines

## Visual Style

**2.5D dioramas:**
- Training ground
- Club facilities
- Player's home
- Stadium

**Match presentation:**
- Commentary feed
- Small pitch view
- Player silhouette
- Ball animation
- Event cards

**UI style:**
- Cards and icons
- Meters and gauges
- NO FM spreadsheets
- JfG-inspired chunky Flash aesthetic

## Non-Negotiables

- JfG DNA always
- Never FM clone
- Never full match control
- Train improves playable skills
- Life competes with football
- Training is default expectation
- Events interrupt (rare, meaningful)
- Stay fast / funny / nostalgic

## Final Feel

**Jumpers for Goalposts grew up — never lost its soul.**
